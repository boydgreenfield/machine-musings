# Minimal shard bundle

A real pytest-coverset-style shard bundle, small enough to read by eye, used by the facts-store
tests and available to later phases (analysis, orchestrator, web) as a known-good input.

Generated by `tests/facts/facts_helpers.py` (`uv run python tests/facts/facts_helpers.py` rewrites this
directory). The generator runs coverage.py 7.16.2 in-process with the ctrace core, branch coverage
and `relative_files`, over the throwaway package in `repo/src/factspkg/`, switching the dynamic
context once per fake test exactly as the plugin does. Everything except `coverage.sqlite` and
`coverage.json` is hand-written.

| Path | What it is |
|---|---|
| `repo/src/factspkg/calc.py` | The measured module: `add`, `classify` (two branches), `never_called`, `excluded` (`# pragma: no cover`), `Box.__init__`, `Box.total` (a loop calling `classify`). |
| `bundle/coverage.sqlite` | coverage.py schema v7, arc data (branch mode stores arcs, not numbits). Contexts: `''` (import time, read as `<import>`) and the five nodeids below. |
| `bundle/coverage.json` | `json_report()` output, format 3: executed/missing/excluded lines and executed/missing branches per file. |
| `bundle/shapes.jsonl.gz` | Addendum B format: a header (3 funcs, 5 shape keys, 5 tests, 6 callers incl. the in-repo caller `Box.total`), 9 `obs` rows and 3 `func_sampling` rows (`classify` is `truncated: true`). |
| `bundle/results.jsonl` | One row per test; `test_zero_fails` failed in the `call` phase. |
| `bundle/collect.json`, `durations.json`, `invariant_links.jsonl`, `meta.json` | Collection items (`{"items": [...], "errors": []}`), per-test durations, one invariant link (`{"test_id": "…::test_add", "invariant_id": "add_commutes"}`, the plugin's format), producer metadata. |
| `bundle.tar.gz` | The same eight files at the archive root, as a worker would ship them. |

Tests (nodeid → what ran under its context):

- `tests/test_calc.py::test_add` → `add(1, 2)`
- `tests/test_calc.py::test_classify[neg]` → `classify(-3)`
- `tests/test_calc.py::test_classify[pos]` → `classify(5)`
- `tests/test_calc.py::test_box_total` → `Box([1, 2]).total()` (calls `classify` twice)
- `tests/test_calc.py::test_zero_fails` → `classify(0)` (recorded as failed)

`never_called` is never called: its `def` line (17) runs at import time, under `<import>`, but its
body (line 18) never runs, so line 18 is the one missing statement, `tests_covering` for the
body is empty, and its treemap leaf shows 0 of 1 statements covered (def lines belong to `<module>`,
as in coverage.py's own function regions). Every branch is taken by some test. The bundle is regenerated rather than edited:
`coverage.sqlite` and `coverage.json` must stay mutually consistent.
