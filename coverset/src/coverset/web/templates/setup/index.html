{% if not reachable %}

{{ public_url }} is a loopback address. GitHub cannot deliver webhooks to it. Start a tunnel (smee or ngrok, see docs/github.md), set COVERSET_ADMIN_TOKEN (at least 32 characters), then set COVERSET_PUBLIC_URL to the tunnel URL and restart coverset serve before creating the App. coverset refuses a public URL without an admin token.

Option 2: token mode (commit statuses and comments only)

Without an App, coverset can post a commit status named coverset and the sticky PR comment using a token:

  1. Create a fine-grained personal access token limited to the repositories coverset should watch, with Commit statuses: read and write, Pull requests: read and write, Issues: read and write and Contents: read.
  2. Set COVERSET_GITHUB_TOKEN, COVERSET_ALLOWED_OWNERS and a webhook secret of at least 16 characters in COVERSET_GITHUB_WEBHOOK_SECRET.
  3. Add a repository webhook (Settings → Webhooks) pointing at {{ manifest.hook_attributes.url }}, content type application/json, with the same secret and the events Pull requests, Pushes.

Token mode has no check runs, so untrusted pull requests cannot be approved with a button; use COVERSET_UNTRUSTED_PR_POLICY=run_blocked_network or skip.
