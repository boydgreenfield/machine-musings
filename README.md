# machine-musings

Experiments and one-off builds.

- [`bob-dylan-songs/`](bob-dylan-songs/) — every song Bob Dylan released, 1961–2020, as hand-lettered index cards in three.js. Four layouts (a highway of signs, a wall of years, a wall of records, a lexicon), 534 songs, one `InstancedMesh`. The `boyd/bob-dylan-fable` branch holds the earlier deep-space version.
