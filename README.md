# machine-musings

Experiments and one-off builds.

- [`bob-dylan-songs/`](bob-dylan-songs/) — every song Bob Dylan released, 1961–2020, as an explorable three.js universe. Four layouts (a galaxy, a highway, a wall of records, a lexicon), 534 songs, one `InstancedMesh`.
- [`coverset/`](coverset/) — anticipatory CI for agent-written Python on Modal: tests start when a PR opens, likeliest failures first, and a data-flow overlay of the input classes each function's tests never tried.
